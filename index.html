Deployment & Operations

无论是个人笔记本开机自启、远程开发机 HTTPS 子路径反代，还是在 Android 手机 Termux 上随身运行，都有开箱即用的官方方案。

🚀 跨平台开机自启守护进程

免管理员权限自动配置 macOS launchd、Linux systemd 用户服务或 Windows 注册表 Run 自启项。 

pi-web-ui server install --port 8787
pi-web-ui server status
pi-web-ui server restart
pi-web-ui server logs -f

🐳 Docker Compose 一键容器化

挂载 ~/.pi 配置与 ~/.pi-web 数据目录，配合 PI_WEB_TOKEN 口令保护，轻松部署在云服务器或 NAS。 

git clone https://github.com/xing-shuyin/pi-web-ui.git
cd pi-web-ui
PI_WEB_TOKEN=secret docker compose up -d

🛡️ Nginx 子路径 (/pi/) 反向代理

全服务端路由均由 appUrl() 包装，只需在 Nginx 转发 Host $http_host 与 /ws Upgrade 头即可安全暴露。 

location /pi/ {
  proxy_pass http://127.0.0.1:8787/;
  proxy_set_header Host $http_host;
}
